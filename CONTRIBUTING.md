# 🤝 Guía de Contribución

¡Gracias por tu interés en contribuir a **El Tridente de la Gloria**!

## 📋 Cómo Contribuir

### Reportar Bugs

Si encuentras un bug, por favor:
1. Verifica que el bug no haya sido reportado ya en los [Issues](https://github.com/EstebanCamejo/TridentedelaGloria-2025/issues)
2. Crea un nuevo issue usando la [plantilla de bug report](https://github.com/EstebanCamejo/TridentedelaGloria-2025/issues/new?template=bug_report.md)
3. Proporciona toda la información solicitada en la plantilla

### Sugerir Funcionalidades

Si tienes una idea para una nueva funcionalidad:
1. Verifica que no haya sido sugerida ya en los [Issues](https://github.com/EstebanCamejo/TridentedelaGloria-2025/issues)
2. Crea un nuevo issue usando la [plantilla de feature request](https://github.com/EstebanCamejo/TridentedelaGloria-2025/issues/new?template=feature_request.md)
3. Describe detalladamente tu idea

### Pull Requests

1. Fork el repositorio
2. Crea una rama para tu feature (`git checkout -b feature/AmazingFeature`)
3. Commit tus cambios (`git commit -m 'Add some AmazingFeature'`)
4. Push a la rama (`git push origin feature/AmazingFeature`)
5. Abre un Pull Request

## 📝 Estándares de Código

- Sigue las convenciones de código existentes
- Asegúrate de que tu código esté bien comentado
- Prueba tus cambios antes de hacer commit
- Mantén los commits pequeños y descriptivos

## ✅ Checklist antes de hacer PR

- [ ] El código sigue los estándares del proyecto
- [ ] He probado los cambios localmente
- [ ] He actualizado la documentación si es necesario
- [ ] Mis cambios no generan nuevos warnings
- [ ] He agregado tests si corresponde

---

**Nota**: Este es un proyecto académico. Las contribuciones son bienvenidas pero sujetas a revisión.
